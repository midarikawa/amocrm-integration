# 🚀 AmoCRM Integration - Умная система управления специалистами

Автоматическая система для **интеллектуального распределения** задач из AmoCRM специалистам с использованием Notion, Google Sheets и Telegram.

## ✨ Ключевые возможности

### 🤖 Умное распределение задач
- **Автоматический выбор** лучшего специалиста на основе:
  - ✅ Специализации (вид работ)
  - ✅ Доступности времени (нет пересечений)
  - ✅ Загруженности на день
  - ✅ Географии (близость к другим задачам)

### 📊 Централизованное управление
- **Google Sheets** - база специалистов и расписание
- **Notion** - детальные карточки задач
- **AmoCRM** - источник сделок через webhook

### 📱 Индивидуальное расписание в Telegram
- Каждый специалист получает **персональное расписание**
- Команды: `/schedule`, `/schedule_tomorrow`, `/schedule_week`
- Уведомления о новых задачах в реальном времени
- Кнопки для обновления статуса задачи

## 🎯 Как это работает

```
1. Новая сделка в AmoCRM
   ↓
2. Webhook → Flask Server
   ↓
3. Умный алгоритм анализирует всех специалистов
   ↓
4. Выбирает лучшего по критериям
   ↓
5. Создает задачу в Notion
   ↓
6. Добавляет в расписание Google Sheets
   ↓
7. Отправляет уведомление в Telegram специалисту
```

## 📋 Быстрый старт

### 1. Установка

```bash
cd amocrm-integration
pip install -r requirements.txt
```

### 2. Настройка

Скопируйте `.env.example` в `.env` и заполните:

```env
# AmoCRM
AMOCRM_SUBDOMAIN=your_subdomain
AMOCRM_CLIENT_ID=your_client_id
AMOCRM_CLIENT_SECRET=your_client_secret

# Notion
NOTION_TOKEN=secret_xxxxxxxxxxxxx
NOTION_DATABASE_ID=xxxxxxxxxxxxx

# Google Sheets
GOOGLE_SHEETS_ID=xxxxxxxxxxxxx

# Telegram
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 3. Запуск

```bash
python src/main.py
```

## 🛠️ Технологии

- **Python 3.9+**
- **Flask** - веб-сервер и API
- **python-telegram-bot** - Telegram бот
- **notion-client** - интеграция с Notion
- **gspread** - работа с Google Sheets
- **AmoCRM API** - получение сделок

## 🎯 API Endpoints

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/` | GET | Статус сервера |
| `/health` | GET | Health check |
| `/amocrm/auth` | GET | Авторизация AmoCRM |
| `/amocrm/callback` | GET | Callback для токенов |
| `/webhook/amocrm` | POST | Webhook от AmoCRM |
| `/api/specialists` | GET | Список специалистов |
| `/api/specialists` | POST | Добавить специалиста |
| `/api/tasks/assign` | POST | Переназначить задачу |
| `/api/test/create-task` | POST | Создать тестовую задачу |
