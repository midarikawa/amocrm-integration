## 🔢 Алгоритм оценки специалиста

```python
Базовая оценка: 100 баллов

+ 30 баллов - если специализация совпадает
- 10 баллов - если специализация не совпадает

- 40 баллов - если занят в указанное время

+ 20 баллов - если полностью свободен на день
+ 10 баллов - если загружен менее 4 часов
- 20 баллов - если загружен более 8 часов

+ 10 баллов - если есть задача в том же районе (< 10 км)
+ 5 баллов - если есть задача поблизости (< 30 км)

Выбирается специалист с максимальной оценкой
```

## 🚀 Как запустить

### 1. Установка зависимостей
```bash
cd amocrm-integration
pip install -r requirements.txt
```

### 2. Настройка .env
```bash
copy config\.env.example .env
# Заполните все переменные
```

### 3. Запуск
```bash
python src/main.py
```

### 4. Получение токенов AmoCRM
```
http://localhost:5000/amocrm/auth
```

### 5. Тестирование
```bash
curl -X POST http://localhost:5000/api/test/create-task \
  -H "Content-Type: application/json" \
  -d '{"address": "Москва, ул. Ленина, 1", "date": "2026-05-10", "time": "10:00", "work_type": "Дезинфекция", "cost": 5000}'
```
