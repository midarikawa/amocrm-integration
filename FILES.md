### 💻 Исходный код (6 файлов)

#### `src/main.py` (8,719 байт)
**Главный Flask сервер**
- Endpoints для webhook AmoCRM
- API для управления специалистами
- Авторизация AmoCRM
- Тестовые endpoints
- Инициализация всех сервисов

**Основные endpoints:**
- `/` - статус сервера
- `/health` - health check
- `/amocrm/auth` - авторизация
- `/amocrm/callback` - OAuth callback
- `/webhook/amocrm` - webhook от AmoCRM
- `/api/specialists` - управление специалистами
- `/api/tasks/assign` - переназначение задач
- `/api/test/create-task` - тестовая задача

#### `src/amocrm_client.py` (7,908 байт)
**Клиент для работы с AmoCRM API**
- Авторизация OAuth 2.0
- Получение и обновление токенов
- Извлечение данных из сделок
- Работа с кастомными полями
- Добавление примечаний к сделкам

**Основные методы:**
- `get_auth_url()` - URL авторизации
- `get_access_token()` - получение токенов
- `refresh_access_token()` - обновление токенов
- `extract_lead_data()` - извлечение данных сделки

#### `src/notion_client.py` (7,935 байт)

**Основные методы:**

**Основные методы:**

- `add_specialist()` - добавить специалиста
- `get_specialist_schedule()` - расписание специалиста
- `add_task_to_schedule()` - добавить задачу в расписание

#### `src/telegram_bot.py` (14,646 байт)
**Telegram бот для специалистов**

- Уведомления о новых задачах
- Обновление статусов задач
- Обратная связь от специалистов

**Команды:**
- `/start` - регистрация
- `/help` - справка
- `/schedule` - расписание на сегодня
- `/schedule_tomorrow` - расписание на завтра
- `/schedule_week` - расписание на неделю
- `/tasks` - активные задачи

**Основные методы:**
- `send_task_notification()` - отправка уведомления
- `schedule_today()` - расписание на сегодня
- `schedule_week()` - расписание на неделю
- `button_callback()` - обработка кнопок

#### `src/smart_scheduler.py` (9,895 байт) 🆕
**Умный алгоритм распределения задач**
- Система оценок специалистов
- Учет специализации
- Проверка доступности времени
- Анализ загруженности
- Оценка географии

**Основные методы:**
- `find_best_specialist()` - найти лучшего специалиста
- `calculate_specialist_score()` - рассчитать оценку
- `is_time_slot_available()` - проверка доступности
- `calculate_workload()` - расчет загруженности
- `calculate_distance()` - расчет расстояния
- `optimize_daily_schedule()` - оптимизация маршрута

**Система оценок:**
```
Базовая оценка: 100 баллов
+ Специализация: до +30
+ Доступность времени: до +40
+ Загруженность: до +20
+ География: до +10
```
